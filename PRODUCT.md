# Resenha Pré-Jogo — Contexto de Produto

> Documentação completa em [`docs/`](docs/README.md).

---

## O que é

Aplicação web mobile-first para torcedores do Campeonato Brasileiro Série A. O usuário escolhe seu clube favorito e acompanha próximos jogos, onde assistir, forma dos times, resultados oficiais e classificação — tudo personalizado com as cores do time.

## Problema

Torcedores precisam consultar múltiplas fontes para saber quando joga o time, em qual canal passa, e o resultado completo. A aplicação centraliza tudo em um lugar, com dados atualizados e IA para descoberta de transmissões.

## Stack

Next.js 16 · React 19 · TypeScript 5 · Tailwind CSS 4 · Upstash Redis · Google Gemini 2.5 Flash · API-Football v3 · CBF API · Vercel
