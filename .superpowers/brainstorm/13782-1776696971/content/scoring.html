Fluxo de lock e pontuação

Ciclo de vida de um palpite
1
Usuário palpita — qualquer momento antes do kickoff. Pode editar livremente enquanto jogo não começou.
2
Kickoff — palpite travado automaticamente. Campo vira read-only. Sem possibilidade de edição.
3
Jogo encerrado — API-Football retorna placar final. Cron (30min) detecta, calcula pontos, atualiza rankings.
4
Ranking atualizado — Sorted Sets Redis atualizados. Usuário vê nova posição no ranking global e em cada bolão privado.

Lock na UI — como detectar

Lógica de lock no servidor
// PUT /api/palpites/[fixtureId]
const match = await getCopaFixture(fixtureId)
const kickoff = new Date(match.date)
if (Date.now() >= kickoff.getTime()) {
return 403 // palpite travado
}
// salva palpite normalmente

Palpite sem preenchimento

Se o kickoff chegar e o usuário não tiver palpitado naquele jogo, ele simplesmente não aparece no cálculo — fica com 0 pts naquele jogo. Sem palpite padrão, sem auto-fill. O ranking reflete quem de fato participou.
