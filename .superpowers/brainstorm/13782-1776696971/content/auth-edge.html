Edge cases cobertos

Casos limite e como tratar
Jogo adiado (status: postponed)
Lock é desfeito — palpite volta a ser editável até novo kickoff.
Palpite duplo (PUT no mesmo fixtureId)
Sobrescreve o anterior se ainda não lockado. Atomicidade garantida pelo Redis SET.
Cron roda antes do resultado final
Checa match.status === 'finished' antes de calcular. Se não finalizado, pula.
Cron roda duas vezes no mesmo jogo
Chave score:{userId}:{fixtureId} já existe → pula. Idempotente por design.
Código de convite inválido
GET bolao:code:{code} retorna null → 404 com mensagem amigável.
Usuário já membro do bolão privado
SISMEMBER no set de members → retorna 200 sem duplicar.
